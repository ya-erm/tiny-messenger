# Cloud adapter

Серверный адаптер Tiny Messenger для облачной среды. Содержит обработчики API,
адаптер хранилища и автоматические проверки.

## Разработка

Требуется Node.js 22. Зависимости фиксируются в `package-lock.json`.
Общие модули генерируются скриптом `scripts/build-cloud-prototype.mjs`.
Сборка функции выполняется `scripts/package-cloud-prototype.py`.

Локальные тесты используют синтетические данные и изолированное хранилище:

```sh
node --test cloud/yandex/tests/*.test.mjs
```

Удалённые проверки запускаются отдельно с явно заданной тестовой конфигурацией.
Используйте только выделенные тестовые учётные записи. Адреса, ключи, настройки
развёртывания и результаты рабочих проверок в репозитории не хранятся.
