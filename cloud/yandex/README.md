# Cloud adapter

Серверный адаптер Tiny Messenger для облачной среды. Реализация API на Go
находится в `go/`; вариант на Node.js в `src/` остаётся эталоном совместимости
и резервным вариантом развёртывания.

## Разработка

Нужны Go 1.23.9 и Node.js 22 для проверок совместимости. Зависимости закреплены
в `go.mod` / `go.sum` и `package-lock.json`.

```sh
node scripts/build-cloud-prototype.mjs
python3 scripts/generate-cloud-go-data.py --check
go -C cloud/yandex/go test ./...
node --test --test-concurrency=1 cloud/yandex/tests/*.test.mjs
python3 scripts/package-cloud-go.py
```

Общие константы и набор допустимых реакций генерируются из тех же модулей,
которые использует JS-клиент. После их изменения запускайте генератор без
`--check`. Тесты Go сравнивают HTTP-ответы, правила конфликтов и подписанные
сессии с реализацией Node.js. По умолчанию проверки используют синтетические
данные и хранилище в памяти.

Для проверки адаптера на настоящей YDB отдельно задаётся `TM_GO_LIVE_CONFIG`
с путём к приватному JSON (`connectionString`, `token`, `userId`). Записи
разрешаются только при `TM_GO_LIVE_ALLOW_WRITES=1`: тест создаёт отдельные
временные ключи, удаляет их и проверяет откат регистрации. Не используйте
общие API smoke-тесты с рабочими учётными записями.

## Развёртывание

`package-cloud-go.py` упаковывает только исходники, зависимости и публичные
встроенные данные. `--check` проверяет соответствие архива исходникам.
`deploy-cloud-go.mjs --candidate` создаёт отдельный тестовый тег, сохраняя
рабочую версию. После удалённых проверок `--promote` переключает рабочий тег,
а `--rollback` возвращает предыдущую версию. Проверка кандидата фиксируется
в приватном состоянии развёртывания; устаревший архив переключить нельзя.

Go использует существующий формат хранилища и протокол обмена; миграция
таблиц и обновление веб-клиента для смены серверной реализации не требуются.
Удалённые проверки выполняйте только с выделенными тестовыми аккаунтами.
Адреса развёртывания, ключи, настройки и результаты рабочих проверок
в репозитории не хранятся.
