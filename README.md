# Tiny Messenger

Небольшой мессенджер с веб-клиентом и API для внешних устройств.

## Возможности

- Личные и групповые чаты, редактирование сообщений, реакции и цитаты.
- Изображения, файлы и опросы.
- Контакты и поиск пользователей.
- Выбор канала связи и сохранение локальной истории.
- Установка как PWA, темы, звук и уведомления.
- Вход по секретному токену, редактирование профиля и замена токена.

Доступность отдельных возможностей зависит от настроек выбранного сервера.

## Разработка

Требуются Node.js 22 и pnpm. Пример переменных окружения — `.env.example`.

```sh
corepack enable
pnpm install --frozen-lockfile
cp .env.example .env
pnpm dev
```

Проверка типов: `pnpm typecheck`. Сборка: `pnpm build`.
Дополнительный публичный адрес API задаётся при сборке переменной
`NEXT_PUBLIC_CLOUD_API_ORIGIN`; при Docker-сборке её нужно экспортировать.
Не добавляйте в Git рабочие ключи, базы данных, выгрузки и настройки окружения.

## Проверки

Интеграционные проверки создают временные базы. Для тестов с браузером нужен
Playwright. Проверки удалённого сервера требуют отдельной тестовой конфигурации
и выделенных тестовых учётных записей; обычным тестам рабочая инфраструктура не нужна.
